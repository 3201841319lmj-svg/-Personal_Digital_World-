# 个人数字世界 | Personal Digital World

欢迎来到我的个人数字生态系统。这不是一个普通的代码仓库，而是我的**长期生活、创意、工作和学习的综合入口**。

## 🌍 核心理念

Personal Digital World 是一个有机的、可扩展的个人系统，将我的四大生活维度整合在一起：

```
Personal Digital World
    ↓
├── 01_DreamGarden (织梦家园)  ✨ 创意与创造
├── 02_Work (工作)              💼 职业与生产力
├── 03_Learning (学习)          📚 知识与成长
└── 04_Life (生活)              🏠 生活与管理
```

## 📍 四大领域

### 🎨 **01_DreamGarden（织梦家园）**
我创造的数字世界。包含 AI 应用、游戏系统、产品设计、UI 组件等创意项目。

**主要项目：**
- **Babel_Tavern** - 巴别小馆
- **Pixel_Farm** - 像素农场 AI 家园
- **File_Assistant_Hub** - 文件助手控制台
- **Magic_Workshop** - 魔法工坊
- **Dream_System** - 魔法梦境系统
- **Shared_Core** - 共享核心（Agent框架、Memory系统、UI组件库）

### 💼 **02_Work（工作）**
现实职业和生产力系统。保险工具、客户管理、销售系统、营销内容。

**主要项目：**
- Insurance_Tools - 保险相关工具
- Customer_Manager - 客户管理系统
- Knowledge_Base - 工作知识库
- Marketing_Materials - 营销资料

### 📚 **03_Learning（学习）**
知识成长体系。包含 AI 研究、编程学习、语言学习、演讲训练、阅读笔记。

**主要项目：**
- AI_Research - AI 研究与实验
- Programming - 编程学习
- Language - 语言学习
- Toastmasters - 演讲训练
- Reading - 阅读笔记

### 🏠 **04_Life（生活）**
个人生活管理。财务规划、旅行安排、日常系统、个人知识管理。

**主要项目：**
- Personal_Knowledge - 个人知识库
- Finance - 财务管理
- Travel - 旅行规划
- Health - 健康管理
- Daily_System - 日常系统

### 📦 **99_Archive（存档）**
已停止项目、历史版本、实验性代码、废弃文件的存放地。

## 💡 设计原则

1. **长期维护** - 设计可持续 5-10 年的系统
2. **模块化** - 各领域独立又相互连接
3. **可扩展** - 为新项目和新想法留有空间
4. **知识流动** - DreamGarden 的创新可以反哺其他领域
5. **历史保留** - Archive 保存所有历史，便于查阅

---

## 🛠️ 技术栈概览

跨项目使用的主要技术：

- **AI & LLM** - Claude、GPT、Llama 等模型集成
- **前端** - React、Vue、Next.js
- **后端** - Node.js、Python、Go
- **数据库** - PostgreSQL、MongoDB、Redis
- **基础设施** - Docker、GitHub Actions、云服务
- **UI/Design** - Tailwind、Figma 设计系统

## 📖 如何使用此仓库

### 对于新项目
1. 在合适的领域（01-04）下创建项目目录
2. 在 `PROJECT_INDEX.md` 中注册项目
3. 在项目目录中创建独立的 README.md

### 对于项目停止/归档
1. 将项目移至 `99_Archive`
2. 在存档说明中记录停止原因
3. 保留完整的 Git 历史

### 对于系统更新
- 更新 `ROADMAP.md` 记录进展
- 定期检查和调整分类
- 保持文档同步
