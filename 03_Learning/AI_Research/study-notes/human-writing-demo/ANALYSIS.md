# 整体方法论总结：用 human-writing skill 写小说的完整流程

> 这一篇是给后面所有 AI 宝宝的核心教程。看懂这一篇，相当于把 human-writing skill 的实战用法全学会了。

---

## 一、为什么需要 skill 而不是"自由发挥"

AI 写中文有个通病：**每个字都对，连起来就不像人**。

模型腔的特征：
- 滥用冒号、破折号、省略号
- 翻案句成瘾（"不是X，是Y"）
- 商业黑话（"赋能""底层逻辑""组合拳"）
- 强行三段式（"创新、变革、突破"）
- 假装深刻（"折射出……的深层逻辑"）

**human-writing skill 的核心思路**：
> 不告诉你怎么写好，**只告诉你怎么不写成 AI**。

正面指导（"要有画面感""要有情感"）全是空话。负面清单（"别用这些词"）才是硬约束，可执行。

## 二、check_prose.py 是怎么回事

这是 skill 自带的**自动扫描脚本**，跑在 Python 3 上。

### 用法

```bash
python3 scripts/check_prose.py your-draft.md
```

### 它会扫什么

```
- 汉字数：统计正文字数（不算 Markdown 符号）
- 翻案句：完全的"不是X，而是Y"结构
- 翻案腔变形：局部翻案（"不是X，是Y"出现在一个句子里）
- 同构排比：三句以上同结构句子
- 名词化：动词被改成名词（"实现"被改成"进行实现"）
- 黑话：商业黑话词表（赋能、闭环、底层逻辑……）
- 硬停词：说白了、先说结论、说穿了
- 模型路标：delve、pivotal、tapestry 等英文 AI 高频词
- 需辨语境词：需要根据上下文判断的词
- 抒情词：空洞的抒情（"感人至深""震撼人心"）
- 洞察路标：假装深刻的分析（"揭示了……的本质"）
- 长前置成分：句子前面堆了太多修饰
- 重定语句：被人工重新定义过的句子
- 中文冒号：硬禁
- 破折号：数量异常会报警
```

### 怎么解读结果

```
汉字数 1796
翻案句 0，翻案腔变形 2，同构排比 0，名词化 0，黑话 0，
硬停词 0，模型路标 0，需辨语境词 0，抒情词 0，洞察路标 0，
长前置成分 0，重定语句 0

需要修改
- 中文冒号共 2 处
- 破折号共 2 处

需要人工判断
- 翻案腔变形 2 处
- 短促单句段 1 处
```

**三类结果**：
1. **✅ 0 类** — 直接交稿
2. **⚠️ "需要修改"** — 硬规则违反，必须改
3. **🤔 "需要人工判断"** — 边界情况，自己决定保留还是改

## 三、实战流程（写一篇小说的标准动作）

### 第一步：拿到任务后，先检查材料

skill 的第一条铁律：

> "活人感首先来自材料，其次来自说话位置，最后才是语气。"

**问自己**：
- 用户给了多少具体材料？
- 哪些是可以写进去的细节？
- 哪些是我编出来凑字数的？

**材料不足时**：
- ✅ 去查（用户没说但合理的信息）
- ✅ 追问（用户没说完的事）
- ✅ 缩篇幅（材料少就别写长）
- ❌ 编（这是 AI 写作最大的原罪）

### 第二步：列提纲，不写第一稿

写之前先列提纲。每段要有：
- 一个**场景**（具体地点、人物、动作）
- 一个**变化**（人变了、事变了、知道的事变了）
- 一个**目的**（这段话为什么存在）

**反规则**：

> "把'记录方便''声音保留状态''检索找回旧内容'各解释五遍，手里仍然只有三条材料。" —— SKILL.md 原话

意思是：**没有变化就不要写**。

### 第三步：写第一稿，自由发挥

这一稿**不要管规则**，先写出来。

破折号、冒号、翻案句都可以用——这是为了**释放表达欲**。

### 第四步：跑 check_prose.py，看报告

```bash
python3 scripts/check_prose.py 第一稿.md
```

**记录所有"需要修改"和"需要人工判断"**。

### 第五步：第二轮修改，重点砍标点

**重点砍 3 个**：
- 破折号（默认全砍，按需保留）
- 中文冒号（默认全砍，引原话可保留）
- 翻案腔变形（按"是不是真心在对比"判断）

### 第六步：第三轮修改，处理"需要人工判断"

每个"需要人工判断"的项目**单独决定**：
- 翻案腔变形：是戏剧对比 → 保留；是凑句式 → 砍
- 短促单句段：是对话节奏 → 保留；是排队喊结论 → 砍
- 抒情词：是具体感受 → 保留；是空洞抒情 → 砍

### 第七步：通读一遍，看节奏

检查项都过了之后，**再读一遍**：
- 句子有没有太长的？
- 节奏有没有太拖的？
- 对话是不是太密/太疏？

这一步**不能省**——check_prose.py 是及格线，不是优秀线。

## 四、破折号的"该不该留"判断框架

这是 demo 里最容易踩的坑，单独讲一下。

### 三类破折号

| 类型 | 示例 | 留还是砍 |
|:---|:---|:---:|
| **真停顿** | "我——"（说不下去） | ✅ 留 |
| **真转折** | "我——不是，我是说——" | ✅ 留 |
| **假停顿** | "我自己挑的你。" 他的声音很轻**——**但烛火终于动了。 | ❌ 砍 |
| **假转折** | "我是新来的**——**" 小猫咪，叫我夏目就好。 | ❌ 砍 |

### 判断标准

> 问自己："如果不写破折号，意思会发生重大改变吗？"

- **会** → 留
- **不会** → 砍

**为什么 AI 爱写破折号**：
- 模型不知道怎么停顿，就用破折号假装停顿
- 模型不知道怎么转折，就用破折号假装转折
- 真正的人**不靠破折号停顿**——靠语境、靠语气、靠内容

---

## 五、翻案腔的"该不该留"判断框架

### 翻案句 vs 翻案腔变形

| 名称 | 结构 | 例子 |
|:---|:---|:---|
| **翻案句** | 完整句"不是X，而是Y" | "不是技术问题，而是人的问题。" |
| **翻案腔变形** | 局部对比"不是X，是Y" | "不是红的，是惨白。" |

### 判断标准

> 问自己："去掉'不是X'，只看'是Y'，意思还完整吗？"

- **完整 + 对比强烈** → 保留
- **完整 + 对比弱** → 砍掉前半句
- **不完整** → 砍掉整个翻案结构

### 为什么 AI 爱写翻案

- 翻案结构让句子"看起来有深度"
- 实际上是**廉价的对比**——把两个相近的东西对立起来，制造伪冲突
- 真正的人**很少这样写**——除非真的有强烈对比

## 六、速查清单（写完一篇后过一遍）

```
□ 黑话：有没有"赋能""闭环""底层逻辑"？
□ 模型路标：有没有 delve、pivotal、tapestry（中文翻译）？
□ 硬停词：有没有"说白了""先说结论"？
□ 冒号：正文中有没有中文冒号（除了引原话）？
□ 破折号：有没有可以删掉的？保留的每一处都问"去掉会怎样"？
□ 翻案腔：每一处"不是X，是Y"都问"去掉前半句意思完整吗"？
□ 同构排比：有没有连续三句以上同结构？
□ 抒情词：有没有"感人至深""震撼人心"？
□ 洞察路标：有没有"揭示了……的本质"？
□ 长前置成分：句首有没有堆了太多修饰？
```

跑一遍 check_prose.py，过完这一关 + 自己通读一遍 = 可以交稿。

---

## 七、不要做的事

1. **❌ 不要批量改稿** —— 改稿是一轮一轮做的，不是写完一次过
2. **❌ 不要靠"感觉"判断模型腔** —— 用 check_prose.py 量化
3. **❌ 不要把 skill 当成"风格指南"** —— 它是**硬规则**，不是建议
4. **❌ 不要因为过了 check_prose.py 就觉得完美** —— 它只是及格线
5. **❌ 不要在对话里用 skill 的语气说话** —— skill 只用于书面创作
