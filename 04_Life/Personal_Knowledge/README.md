# 个人知识库 | Personal Knowledge Management

个人知识管理 (PKM) 系统。整理和连接所有的知识片段。

## 🧠 系统架构

### 笔记类型

- **Fleeting Notes** - 临时想法和灵感
- **Literature Notes** - 阅读和研究笔记
- **Permanent Notes** - 永久知识和见解
- **Index** - 主题索引和知识图谱

### 知识领域

- **技术** - 编程、AI、工具
- **思维** - 哲学、心理学、科学
- **创意** - 艺术、设计、写作
- **生活** - 健康、财务、人际
- **业务** - 营销、销售、管理

## 📚 知识库结构

```
Personal_Knowledge/
├── fleeting/          # 临时笔记
├── literature/        # 阅读笔记
├── permanent/         # 永久笔记
├── index/            # 主题索引
└── graphs/           # 知识图可视化
```

## 🎯 目标

- 建立完整的知识体系
- 促进知识之间的连接
- 方便检索和应用
- 定期回顾和优化
