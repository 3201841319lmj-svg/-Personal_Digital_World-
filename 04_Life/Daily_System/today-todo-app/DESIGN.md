# 今日烘焙单｜设计规范

版本：1.1
更新日期：2026-09-02

## 1. 产品目标

“今日烘焙单”是一款轻量、低压力的单日待办工具。界面以咖啡店和烘焙纸张为视觉隐喻，让任务管理保持温暖、安静、易读。

产品只覆盖以下核心流程：

1. 查看今天的三个任务板块。
2. 新增、完成和删除任务。
3. 为任务增加子任务。
4. 从左上角历史菜单查看最近 15 天。

不加入提醒、标签、统计图表、社交、积分或其他未明确要求的功能。

## 2. 视觉方向

关键词：咖啡、烘焙纸、手帐、小猫陪伴、克制可爱。

- 深咖啡色主视觉承载品牌标题和小猫插画。
- 奶油纸色作为页面和任务卡背景，避免纯白造成的冷感。
- 焦糖色用于边框、焦点和序号，不大面积铺色。
- 莓果红只用于删除等风险操作。
- 卡片使用轻微不对称圆角，保留手帐感但不影响信息密度。

## 3. 设计变量

| 角色 | 变量 | 色值 |
|---|---|---|
| 页面底色 | `--cream` | `#f7f0e4` |
| 卡片纸色 | `--paper` | `#fffaf1` |
| 主文字 | `--espresso` | `#35241d` |
| 品牌咖啡色 | `--coffee` | `#795642` |
| 次级棕色 | `--latte` | `#b88967` |
| 强调焦糖色 | `--caramel` | `#d89a56` |
| 风险操作 | `--berry` | `#9b4d42` |
| 完成状态 | `--sage` | `#8b9175` |

重复出现的颜色、阴影和边框必须继续使用 CSS 变量，避免组件内散落新的近似色。

## 4. 字体与层级

- 品牌标题及板块标题：`Georgia, "Songti SC", serif`。
- 正文及控件：`"Noto Sans SC", "Microsoft YaHei", sans-serif`。
- 手机端品牌标题为 38px；板块标题为 18px；任务正文为 12px。
- 日期使用奶油色高对比标签，只显示实际日期，例如“8月24日周一”，不重复显示“今天”。
- 页面不显示任务数量、完成比例或空白日程提示。

## 5. 页面结构

```text
页面
├─ 左上角历史菜单图标
├─ 品牌主视觉
│  ├─ 英文眉题
│  ├─ 今日烘焙单
│  ├─ 简短说明
│  ├─ 当前日期
│  └─ 小猫 SVG
├─ 今天要完成
├─ 今天想推进
├─ 有空再处理
└─ 页尾鼓励语
```

桌面端三个任务板块横向排列；宽度低于 850px 后改为单列。

## 6. 手机端规则

- 页面左右留白 9px。
- 品牌卡高度约 218px，小猫位于右下角，不能遮挡日期。
- 历史入口固定在品牌卡左上角，只显示三横线图标；通过 `aria-label` 和 `title` 保留可访问名称。
- 最近 15 天不在页面铺开，仅在历史菜单中展示。
- 任务卡间距 10px、内边距 14px，保证单手浏览密度。
- 页面不得产生横向滚动。

## 7. 核心组件

### 历史菜单

- 点击左上角图标展开最近 15 天。
- 当前日期使用深咖啡色选中态。
- 选择日期后菜单自动关闭。
- 菜单内容可以纵向滚动，不扩大页面高度。

### 任务与子任务

- 圆角复选框代表任务完成状态。
- 父任务完成时，其直接子任务同步完成。
- 子任务通过任务行右侧入口展开输入框。

### 删除确认

- 第一次点击删除图标不得删除数据。
- 第一次点击后原位显示“确认 / 取消”。
- 只有点击“确认”才执行删除；“取消”恢复删除图标。
- 删除父任务时同时删除其子任务。

## 8. 插画与资源

- 主视觉为 `public/cat-baker.svg`。
- SVG 必须保持矢量格式并小于 200KB；当前文件为 1,380 bytes。
- 手机桌面与 PWA 图标采用 `CAT-001 / Baker` 大颗粒像素猫，母版位于 `public/icons/icon-master-1024.png`。
- Manifest 使用 `192×192`、`512×512` 和独立 maskable 图标；Apple Touch Icon 使用 `180×180`。
- 图标家族遵循仓库根目录 [`PIXEL_CAT_ICON_SYSTEM.md`](../../../PIXEL_CAT_ICON_SYSTEM.md)，后续项目不得自行改变猫猫基础轮廓、像素颗粒和安全区。
- 不引入带有第三方版权不明的角色图片、字体文件或远程图片。

## 9. 可访问性

- 所有图标按钮必须具有 `aria-label`。
- 键盘焦点使用焦糖色 3px 外框。
- 交互不能仅依赖颜色表达状态。
- 支持 `prefers-reduced-motion`，用户减少动态效果时取消过渡。
- 小猫插画提供中文替代文本。

## 10. 数据与部署边界

- SQLite 是权威数据源，生产数据库位于 CVM Docker 持久化卷。
- `localStorage` 只用于服务器空库时迁移旧数据，以及服务器故障时显示最近缓存。
- 单用户密码门禁由 Nginx Basic Auth 提供，不在产品界面增加注册或账号管理。
- 容器端口只绑定 `127.0.0.1:3010`，API 不直接暴露公网。
- 数据库、备份、密码文件、证书私钥和 DNSPod Token 禁止提交到仓库。
- 保留三个板块、子任务、15 天历史与删除确认；服务器存储改造不得扩展产品功能。

## 11. 变更检查

每次视觉或交互修改后至少执行：

```bash
npm run lint
npm run typecheck
npm run build
```

涉及响应式布局时，还需在 390px 手机视口和桌面视口检查文本溢出、横向滚动、菜单遮挡及控制台错误。
