## 💡 如何归档项目

1. 创建一个文件夹，使用格式 `[日期]_[项目名]`
2. 包含项目的所有文件
3. 添加 `ARCHIVE_INFO.md` 说明：
   - 项目完成时间
   - 停止原因
   - 关键成果
   - 学到的经验
4. 在此README中添加条目
