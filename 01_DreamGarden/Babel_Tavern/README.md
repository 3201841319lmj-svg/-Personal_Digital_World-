# 巴别小馆 | Babel Tavern

一个多语言、多文化的虚拟社交空间。在这里，来自世界各地的 AI 角色聚集交流，用多种语言讲述故事。

## 🎭 概念

- **设置** - 一间魔法酒馆，时空交界
- **角色** - 各种来自不同文化背景的 AI 角色
- **互动** - 多语言对话、故事共创、知识交换
- **体验** - 沉浸式的社交和创意体验

## 🎯 项目目标

**MVP 目标**
- 实现基础的聊天界面
- 集成 Claude API
- 创建 3-5 个独特的 AI 角色
- 多语言支持（至少英文、中文）

## 🛠️ 技术栈

**前端**
- React + TypeScript
- Tailwind CSS
- Socket.io (实时通信)

**后端**
- Node.js + Express
- Claude API
- PostgreSQL

## 📊 角色设定

### 主要角色（预计）

1. **酒保 Aldwin** - 英文，知识渊博的主持人
2. **诗人 Luna** - 中文，感性而富有想象力
3. **旅人 Kael** - 日文，冒险家和讲故事者
4. **学者 Iris** - 多语言，AI 和哲学研究者
