# 魔法梦境系统 | Dream System

个人梦想追踪和可视化系统。将您的梦想转化为可追踪的目标，用数据和可视化见证成长。

## 🌙 概念

- **梦想管理** - 收集、分类和优先级排序梦想
- **目标分解** - 将大梦想分解为可执行的小目标
- **进度追踪** - 实时追踪目标的进展
- **可视化** - 用美观的图表和动画展示进度
- **反思工具** - 定期回顾和反思

## 🎯 项目目标

**MVP 目标**
- 梦想和目标的 CRUD 操作
- 基础的进度追踪
- 简单的可视化
- 周/月报告生成

## 🛠️ 技术栈

**前端**
- Vue 3 + TypeScript
- Vite
- Chart.js / D3.js (可视化)
- Tailwind CSS

**后端**
- Node.js + Express
- PostgreSQL
- GraphQL

```bash

npm install
npm run dev

# 前端
cd frontend
npm install
npm run dev
```
