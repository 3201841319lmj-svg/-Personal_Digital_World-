# 文件助手控制台 | File Assistant Hub

`File_Assistant_Hub` 是 **Personal Digital World** 生态中 **01_DreamGarden（织梦家园）** 板块下的核心生产力控制台项目。

## 📍 项目定位

- **定位**：集成了文件收集、主题看板、AI Agent 作用域（Agent Scope）、动态 Feed 消息流、收藏夹管理及任务目标维度的文件助手控制台。
- **状态**：🔄 进行中 (In Progress)
- **技术栈**：React 19 + TypeScript + Vite + Lucide Icons + Tailwind / CSS Modules
- **对应路径**：`01_DreamGarden/File_Assistant_Hub`

## 🌟 核心功能

1. **主题与 Feed 消息流 (Feed View)**：
   - 按主题分类（如客户方案、OpenClaw研究、灵感收集、旅行计划、健身记录等）管理各种格式的文件（PDF、图片、文本、AI Agent 对话）。
2. **AI Agent 作用域管理 (Agent Scope)**：
   - 配置与连接 OpenClaw 及各种 AI 智能体的数据访问边界与互动记录。
3. **任务与目标管理 (Target View)**：
   - 将接收到的文件与信息快速转化为跨维度 Task 目标（工作、学习、生活、健康、医疗）。
4. **收藏与归档 (Archive View & Favorites)**：
   - 支持敏感文件保护、受限模式管理、自动过期倒计时与离线存储分析。

## 🚀 本地运行

```bash
cd 01_DreamGarden/File_Assistant_Hub
npm install
npm run dev
```
