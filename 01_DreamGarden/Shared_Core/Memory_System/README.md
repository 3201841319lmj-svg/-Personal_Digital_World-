# Memory System | 记忆和上下文系统

为 DreamGarden 中的 AI Agent 提供长期记忆、短期上下文和知识检索能力。

## 📋 功能

- [ ] 短期上下文窗口管理
- [ ] 长期记忆存储
- [ ] 向量化和语义搜索
- [ ] 记忆检索和更新
- [ ] 遗忘和记忆衰减机制

## 🛠️ 技术栈

- PostgreSQL / Vector DB
- Embeddings (OpenAI / Local)
- Node.js + TypeScript
