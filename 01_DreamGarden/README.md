## 🚀 快速开始

### 添加新项目

1. 在本目录下创建新项目文件夹
2. 创建 `README.md` 说明项目
3. 在 `PROJECT_INDEX.md` 中注册

### 使用 Shared_Core

在您的项目中引入共享组件和框架：

```typescript
import { AgentFramework } from '../Shared_Core/Agent_Framework';
import { MemorySystem } from '../Shared_Core/Memory_System';
import { UIComponents } from '../Shared_Core/UI_Components';
```
