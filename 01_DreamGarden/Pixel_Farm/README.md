# 像素农场 | Pixel Farm

AI 驱动的虚拟农场和家园管理系统。在这个虚拟世界中，您可以种植庄稼、管理资源、建造家园。

## 🌾 概念

- **农场** - 虚拟的农场，可以种植各种作物
- **家园** - 可定制的虚拟家园
- **AI 伙伴** - 帮助管理农场的 AI 助手
- **交易系统** - 与其他玩��或 AI 商人交易
- **进度系统** - 通过游戏机制推进故事

## 🎯 项目目标

**MVP 目标**
- 基础的农场种植系统
- 资源管理和收获
- AI 辅助决策
- 数据持久化
- 基础的可视化

## 🛠️ 技术栈

**前端**
- Next.js + TypeScript
- Canvas / Three.js (可视化)
- React Query

**后端**
- Python + FastAPI
- PostgreSQL
- Redis (缓存)

**AI/ML**
- Claude API (决策)
- 简单的算法 (农业模拟)

## 🚀 快速开始

```bash
# 克隆或初始化项目
cd Pixel_Farm

# 后端
cd backend
pip install -r requirements.txt
python main.py

# 前端
cd frontend
npm install
npm run dev
```
